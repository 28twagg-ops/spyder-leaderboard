# Pregnancy Info App + legacy SPYDER leaderboard

This repository contains two independent projects.

- [Pregnancy Info App — start here](pregnancy-info-app/README.md): architecture, design and research transfer brief for Claude in Cursor.
- Legacy SPYDER leaderboard: existing Flask/PostgreSQL backend in `server.py` and `requirements.txt`. Preserved unchanged; do not assume it is safe to shut down its deployment or database.

The app is an educational maternal-health research and preparation project, not a clinical service. No personal health information belongs in this public repository. Do not commit journal entries, images, identifiers, credentials or private records.

Proposed repository name: `pregnancy-info-app-and-old-spyder-leaderboard`. Repository settings and deployment changes are outside this documentation commit.
